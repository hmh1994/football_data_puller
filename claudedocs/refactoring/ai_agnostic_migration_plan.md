**직접 참조**:

- ✅ 코드에서 `claude*` 모듈을 import하지 않음
- ✅ 설정 파일에서 Claude를 참조하지 않음
- ⚠️ 디렉토리 이름이 Claude 소유권을 암시
- ⚠️ `CLAUDE.md`가 Claude Desktop 전용

**간접 참조**:

- 문서에서 "Claude 분석" 언급
- 커밋 메시지에 Claude 참조 가능
- 개인 워크플로우 가정 (Claude Desktop)

## 코드 스타일 선호도

### Python `__init__.py` 파일

**규칙**: `__init__.py` 파일을 비워두기

**근거**:

- 명시적 import가 가독성 향상
- 순환 import 이슈 방지
- 명확한 모듈 경계

**예시**:

```python
# ❌ 피하기
# football_data_manager/common/__init__.py
from .repositories import Base
from .services import DbService

# ✅ 권장
# football_data_manager/common/__init__.py
# (빈 파일)
```

## 지원되는 AI 도구

이 프로젝트는 **AI 중립적**입니다. 어떤 AI 코딩 어시스턴트도 사용할 수 있습니다:

- ✅ Claude Desktop / Claude Code
- ✅ GitHub Copilot
- ✅ Cursor IDE
- ✅ OpenCode
- ✅ Codeium
- ✅ 기타

## 가이드라인

### 1. **코드 생성**

**권장사항**:

- 보일러플레이트 코드(테스트, CRUD 작업)에 AI 사용
- 문서 생성에 AI 사용
- 리팩토링 제안에 AI 사용

**비권장사항**:

- 검토 없이 AI 생성 코드를 무조건 수용
- 테스트 없이 AI 생성 코드 커밋
- 전문가 검토 없이 보안 중요 코드에 AI 사용

### 2. **문서화**

**AI 생성 문서는 반드시**:

- 메타데이터 헤더 포함 (아래 템플릿 참조)
- 병합 전 사람이 검토
- 커밋 메시지에 "AI 생성" 표시

**템플릿**:

```markdown
---
ai_generated: true
generated_date: YYYY-MM-DD
ai_tool: <tool name>
reviewed_by: @username
status: draft|approved
---
```

### 3. **커밋 메시지**

**AI 보조 커밋 형식**:

```
type(scope): description

AI-assisted: <tool name>
Reviewed-by: @username
```

**예시**:

```
feat(scoring): implement Bayesian shrinkage algorithm

AI-assisted: Claude Sonnet 4
Reviewed-by: @jormal

- Added shrink_per90() and shrink_ratio() functions
- Implemented position-weighted overall score
- Added comprehensive unit tests
```

### 4. **코드 리뷰**

**검토자는 반드시**:

- AI 생성 코드 정확성 검증
- 잠재적 보안 이슈 확인
- 테스트가 엣지 케이스를 커버하는지 확인
- 비즈니스 로직 정확성 검증

### 5. **공식 & 알고리즘 검증**

**중요**: 모든 AI 생성 공식은 반드시:

1. 사양에 대해 수동 검증
2. 알려진 입력/출력으로 테스트
3. 예제와 함께 문서화
4. 도메인 전문가의 피어 리뷰

**예시**: `calculation_formulas_reference.md`의 Player 점수 알고리즘
